# Suitable-area share

Adapted from spark01 `release/suitable_area_share/compute_and_plot.py`.
This code-only directory includes neither rasters nor capacity/statistics tables.

The statistic is the **unweighted mean of per-grid suitable fractions** among
grids with `capacity_YYYY > 0`, multiplied by 100. It is not capacity-weighted
and is not the ratio of total suitable area to total national area.

Default `--area-method lonlat0p1`: project each 0.1° × 0.1° cell into the suitability
mask CRS and count raster-pixel centres within it. Suitable value is 0; nodata is
excluded. `window10km` uses a 10 km × 10 km window and is a different area definition.
Province bars are ordered by total capacity; built-in abbreviations are used unless
an optional `--prov-attr-csv` (`name,abbr`) is provided.

## Recompute

Requires wind and solar capacity CSVs with `lon`, `lat`, `province`, and
`capacity_YYYY`, plus corresponding projected suitability GeoTIFFs. The source
used wind v3 / solar v2 capacity tables and 1 km Albers masks. Both wind and solar
inputs are required by this retained comparison workflow.

```bash
python -m pip install -r application/requirements-recompute.txt
python application/suitable_area_share/compute_and_plot.py --compute --plot --wind-csv /path/to/wind.csv --solar-csv /path/to/solar.csv --wind-mask /path/to/wind.tif --solar-mask /path/to/solar.tif --cache-dir /path/to/new_stats --out-dir outputs/suitability
```

Alternatively set `--base-dir /path/to/external_root` (or `NATURE_ENERGY_ROOT`)
containing `data/history_capacity_new_by_province/grid_cmfd_wind_all_v3.csv`,
`grid_cmfd_solar_all_v2.csv` in the same directory, and masks under
`data/suitable_position/China/gridcerf-china/compiled/` named
`gridcerf_wind_onshore_hubheight100m_strict.tif` and
`gridcerf_solar_pv_centralized_strict.tif`. Explicit file options override defaults.

## Plot existing statistics

```bash
python application/suitable_area_share/compute_and_plot.py --plot --cache-dir /path/to/stats --out-dir outputs/suitability
```

For each of `wind` and `solar`, default plotting needs
`stats_{technology}_suitable_area_share_anchor_years_lonlat0p1.csv` and
`stats_{technology}_suitable_area_share_{year}_by_province_lonlat0p1.csv` for
2014 and 2024. Use the table schemas generated by `--compute`. Default outputs
include two national figures and four province figures. Use distinct caches for
different capacity-table versions and area methods.
